\# Jenkins CI/CD Pipeline Demo



\## Overview

This project demonstrates a complete CI/CD pipeline built using Jenkins, 

integrated with GitHub for source code management.



\## Pipeline Stages

| Stage | Description |

|-------|-------------|

| Checkout | Clones source code from GitHub |

| Build | Compiles the application |

| Test | Runs unit and integration tests |

| Code Quality Check | Analyzes code quality |

| Deploy | Deploys the application to server |



\## Tools Used

\- Jenkins 2.555.2

\- Git

\- GitHub
